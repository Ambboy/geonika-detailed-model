# Геоника — рабочий предпросмотр

Промежуточная браузерная модель здания и окружения, опубликованная для визуального осмотра владельцем. Это **не финальная приёмка качества**, не инженерная/BIM-модель и не подтверждение скрытой конструкции кровли.

## Состав

- Геометрия и материалы из текущей работоспособной версии; детализация части галереи загружается по виду камеры.
- Исходная окраска сканирования и отдельно обозначенные восстановленные поверхности/варианты отделки.
- Сохраняются шум, пробелы, упрощённые участки и условная центральная кровля.
- Последний неработающий эксперимент с южным переходом кровли **не включён**.

Статическое дерево сайта — `docs/`. Для локального просмотра обслуживайте эту папку обычным HTTP-сервером; открытие через `file://` не поддерживается. Внешние CDN и загрузка исходных облаков не нужны.

Кнопки **Exterior** — внешний вид, **Gallery** — галерея, **Exhibits close-up** — крупный план, **Clay** — геометрия без исходной окраски. **Inferred geometry** переключает показ восстановленных поверхностей. Эта настройка не восстанавливает исходные поверхности, заменённые на более ранних этапах обработки.

Старая страница-прототип не заменяется. Оригинальные облака, приватные исходники обработки, служебные отчёты и учётные данные в этот репозиторий не включены.
