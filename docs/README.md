# Геоника — промежуточная браузерная модель

Рабочий предпросмотр текущей модели здания и окружения для осмотра владельцем. Это не финальная художественная приёмка, не инженерная/BIM-модель и не подтверждение скрытой конструкции кровли.

- **Exterior** — общий внешний вид; **Gallery** — галерея; **Exhibits close-up** — крупный план.
- **Generated finish / C0 baseline / Clay** — варианты отображения материалов и геометрии.
- **Inferred geometry** — показ/скрытие восстановленных поверхностей; это не восстановление исходных поверхностей, заменённых на предыдущих этапах.
- Сохраняются шум сканирования, пробелы, упрощённые поверхности и условная центральная кровля.
- Последний неработающий эксперимент с южным переходом кровли не включён.

Модель статическая; её нужно обслуживать по HTTP/HTTPS, а не открывать через `file://`. Ассеты и библиотеки находятся в этом дереве; исходные облака и внешние CDN не требуются. Детализация части галереи выбирается по камере, не более четырёх самых подробных частей одновременно.

Геометрия, материалы и логика просмотра сохранены из текущей работоспособной версии. Для публичного хостинга учтено HTTP-сжатие: размер переданных сжатых данных не смешивается с точным размером декодированного файла. Ограничения объёма и проверки SHA-256 остаются включены.
