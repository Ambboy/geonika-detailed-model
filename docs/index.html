Промежуточная модель для осмотра — не финальная приёмка и не инженерная реконструкция. Exterior — снаружи; Gallery — галерея; Clay — геометрия без окраски. Inferred geometry скрывает восстановленные поверхности, но не возвращает ранее заменённую исходную геометрию. Есть шум, пробелы и упрощённые участки; скрытая форма центральной кровли условная. Цвет сканирования — не фототекстура. Последний неработающий переход кровли не включён.
